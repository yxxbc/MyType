## 选词学习与输入统计

用空格、数字键或鼠标确认候选后，MyType 会在本机学习选词偏好。一次选错的单字不会立刻抢占首选；近期反复确认的单字可以升到首位。撤销的分段选词、直接上屏的原始拼音和英文候选不学习。想忘掉误学的候选，选中该项再按 `Control+Delete`。

设置 →「学习」里可以关掉自动学习，或者清除已经学到的词、热度和搭配；自定义词（`custom.tsv`）不受影响。清除后输入法会清掉内存里的学习数据并保存空表，下次从头学。

在「MyType 设置 → 输入统计」打开记录，可以看今天的汉字数、上屏次数，以及 7 / 14 / 30 / 90 天的趋势。默认关闭，不补算过去；只在本机保存日计数，不记录原文、键位或应用名称。安全键盘输入开启时不计数。统计页也能清除本机保存的每日计数。

词库在第一次聚焦输入框时载入；离开输入框两分钟，或系统发出内存压力通知且没有活跃输入框时，可释放词库。再次输入时会重新载入。语音对象只在使用热键时创建，闲置两分钟或关闭语音时释放。互译的本地 `llama-server` 闲置按设置释放，内存压力、关掉互译或退出输入法时也会停。

## MyType 灰了或菜单重复

先在「文本编辑」新文稿的正文里测试，不要在密码框或密码自动填充面板里测试。若系统拼音能用、MyType 仍无法选择，可到「系统设置 → 键盘 → 文字输入 → 编辑」移除 MyType 输入源，再添加一次。移除输入源不会删除用户词库。

如需排查，可以在终端运行以下**只读**命令，查看当前输入源、MyType 注册条目和安全键盘输入状态：

```sh
"$HOME/Library/Input Methods/MyType.app/Contents/MacOS/MyType" --input-status
```
