# 设置与配置

MyType 的设置有三处：设置窗口（输入法菜单 →「MyType 设置…」）、配置文件
`~/Library/Application Support/MyType/mytype.conf`、自定义词 `custom.tsv`。
设置窗口改完下一次按键就生效，不用重启输入法。

## 自定义词

加进去的词总是排在候选第一个，简拼也能打：加了「字节跳动」（`zi jie tiao dong`），打 `zijietiaodong` 或者 `zjtd` 都能出来。

自定义词存在 `~/Library/Application Support/MyType/custom.tsv`，一行一个，也可以手动编辑：

```
# 编码<TAB>词[<TAB>频次]
zi jie tiao dong	字节跳动
zhangwei	张伟
mail	hello@example.com
di zhi	四川省\n宜宾市
```

- 编码一般是拼音，可以用空格隔开音节，也可以连着写（`zhangwei`）。
- 编码也可以不是拼音，只要全是字母（`mail`、`addr`）：正好打这几个字母时，这个词排第一。
- 词里写 `\n` 表示换行、`\t` 表示制表符，上屏时换成真的；候选窗里画成 `⏎`。带换行的词不记进自动学习。
- 设置窗口「自定义词」页右上角能**导入**、**导出**这种文件。导入时同一个词用文件里的编码，别的词保留。
- 自定义词也是**常用语**：只打一个 `v` 再按空格打开[工具栏](#v--空格工具栏)，「常用语」里按文件顺序列出全部，选一条上屏。
- 手动改完文件，切回输入法下一次按键时自动重新读；设置窗口开着时切回窗口也会重新读。

## 互译

在设置窗口「翻译」里下载本地模型，或者在「用什么翻译」里选「自定义翻译服务」填一个 OpenAI 格式（`chat/completions`）的接口，打开「互译」，
单按 Shift 就在 **中 → 英 → 译 → 中** 之间切换（没填好服务时只在中英之间切）。
也可以在「输入」页设一个**互译的快捷键**（`TranslateModeKey`，比如 `Ctrl+Shift+Y`）：按它进「译」，在「译」里再按回到原来的模式（中文或英文）；设了以后单按 Shift 只在中英之间切。

切到「译」后照常打中文：打的字攒在候选框里（顶上写着「中→英 互译」），不上屏；停 0.5 秒（打了句号、问号就立刻）发给服务，译文边出边写进输入框（带下划线），只给一种。
接着打字时输入框里先留着上一句的译文，新的出来再换。

| 键 | 作用 |
|---|---|
| `回车`、`空格` | 上屏译文；还没译完就等译好了自动上屏 |
| `Shift+回车` | 上屏原文 |
| `退格` | 删原文最后一个字，停一下重新翻 |
| `Esc` | 清空原文 |
| 单按 `Shift`、另设的切换键 | 回到中文，原文原样上屏 |
| 互译的快捷键 | 回到进「译」之前的模式，原文原样上屏 |

- 打的是外文（比如英文）就翻成中文。数字、`/` `+` 这些符号也进原文。
- 同一句话翻过一次会记住（最近 64 句），再打不用等。出错时候选框底下写原因，按回车重试。
- 有的程序不让输入法把编辑区画在它的输入框里，这时译文写在候选框最下面一行。
- **打的字会发给你填的服务**（MyType 自己不经手）。密码框里不翻译。
- API Key 存在 `~/Library/Application Support/MyType/translate.key`（权限 0600，只有自己能读），不写进 `mytype.conf`、不进日志。
  设置窗口的「文件」菜单或输入法菜单「设置互译 API Key…」可以改。本机的服务（Ollama 等）可以不填。
- 走系统的网络设置（包括系统代理）；连本机的服务不走代理。
- 打字时要等它翻译，挑又小又快的模型（各家的 mini、flash、turbo 版）；推理模型会慢很多。设置里的「测试连接」会显示一次要多久。

### 本地模型（离线）

不想把字发出去，可以在「翻译」页的「用什么翻译」里选「本地模型（离线）」（默认就是它），用腾讯混元的翻译模型
[HY-MT 1.5 1.8B](https://huggingface.co/tencent/HY-MT1.5-1.8B-GGUF)（Q4_K_M，1.13 GB）在本机翻：

- 模型点「下载」获取，放在 `~/Library/Application Support/MyType/models/`（`TranslateLocalModel` 写了位置就下到那里），
  下载完校验 SHA256，断了再点会接着下（接着下时不用再确认许可）。
  命令行也行：`~/Library/Input\ Methods/MyType.app/Contents/MacOS/MyType --download-model`（加 `--accept-license` 跳过确认）。
- 跑模型用 llama.cpp 的 `llama-server`，不用自己装：系统里没有时，下载模型会顺带从
  [llama.cpp 的发布页](https://github.com/ggml-org/llama.cpp/releases)下载官方 macOS 程序
  （Apple 芯片约 17 MB、Intel 约 12 MB，MIT 许可，钉死一个版本并校验 SHA256），解到数据目录的 `llama/`，
  设置里能删。它要 macOS 13.3 以上；更老的系统自己装 llama.cpp（`brew install llama.cpp`）。
- 找 `llama-server` 的顺序：设置里填的路径 → 数据目录下载的那份 → `/opt/homebrew/bin`、`/usr/local/bin`、`/opt/local/bin`。
- 第一次翻译时才启动 `llama-server`（只监听 127.0.0.1 的随机端口，载入要几秒），
  闲置 `TranslateIdleMinutes` 分钟（默认 5）后停掉，内存还回去；关掉互译、系统内存压力或退出输入法时也停。
  翻译时 llama-server 占 1.5 GB 左右内存，一句话 1–3 秒。
- **许可**：模型用的是腾讯混元社区许可协议（Tencent HY Community License），不是开源协议。
  它**不适用于欧盟、英国和韩国**；月活超过 1 亿的产品要另找腾讯授权。MyType 不分发这个模型，
  是你自己从 Hugging Face 下载，下载前设置窗口会让你确认。[协议全文](https://huggingface.co/tencent/HY-MT1.5-1.8B/blob/main/License.txt)

## v + 空格：工具栏

全拼下只打一个 `v`、再按空格，打开工具栏（`vim`、`vscode` 这些照常打字，`v1+2*3` 照常算算式）：

| 项 | 内容 |
|---|---|
| 剪贴板 | 最近复制过的文字，最新的在前，最多 20 条 |
| 常用语 | [自定义词](#自定义词)，按 `custom.tsv` 里的顺序 |
| 符号 | 全部内置符号；也能打拼音搜（`youjiantou` → →） |
| 表情 | 和 `Control+.` 打开的表情面板一样 |

数字键或方向键加空格/回车选择，退格返回上一层，Esc 关闭；工具栏开着时别的键不会打进应用，`Ctrl+C` 这类组合键会收起工具栏、交给应用。

**剪贴板历史默认关**，在设置「输入」页打开「记录剪贴板历史」（`ClipboardHistory=True`）。打开后只在内存里记，不写到磁盘，输入法进程退出就清空；再关掉时立刻清空。
切换输入框、打开工具栏的剪贴板页时各看一次系统剪贴板，所以连着复制了好几次、中间没切换输入框的话，只记得到最后一次。

**密码**：光标在密码框里时不取剪贴板。很多密码管理器复制密码时会给剪贴板标上 `org.nspasteboard.ConcealedType`，
带这个标记（还有 `TransientType`、`AutoGeneratedType`）的不记；没按这个约定标记的密码管理器复制的密码会被记下、在工具栏里明文显示，用这类密码管理器的话保持关闭。
新版 macOS 读剪贴板时可能会问要不要允许 MyType 读，不允许就没有记录。

互译模式（「译」）下不开工具栏。

## 配置文件

设置存在 `~/Library/Application Support/MyType/mytype.conf`，一行一个 `键=值`，`#` 开头的行是注释。
文件不存在、或者少写了哪一项，就用默认值。设置窗口只改它认识的键，注释、不认识的键、`[分组]` 原样留着。

```ini
CandidateLayout=Horizontal
ArrowKeys=Candidates
PageSize=9
CandidateFontSize=17
SelectKeys=Off
TypoCorrection=True
InputScheme=Quanpin
ShiftToggle=Both
Traditional=False
PunctuationStyle=Fullwidth
Toolbar=True
ClipboardHistory=False
InputStatistics=False
AutoLearn=True
Voice=True
VoiceKey=Alt_R
EmojiKey=Control+period
CheckUpdate=True
Translate=False
TranslateLocal=True
```

完整的键和默认值以 [`spec/config.json`](../spec/config.json) 为准（`macos/test.sh` 拿它对照代码），常用的分几组：

| 组 | 键 | 说明 |
|---|---|---|
| 候选 | `CandidateLayout`、`ArrowKeys`、`PageSize`、`CandidateFontSize`、`PageKeysMinusEqual`、`PageKeysBracket`、`PageKeysCommaPeriod`、`PageKeysTab`、`SelectKeys`、`PickChar` | 横排 / 竖排、方向键选词还是移光标、每页 3–9 个、字号 10–40 磅、翻页键、分号引号选词、`[` `]` 以词定字 |
| 模糊音 | `Fuzzy`、`FuzzyZh`、`FuzzyCh`、`FuzzySh`、`FuzzyNL`、`FuzzyFH`、`FuzzyRL`、`FuzzyAn`、`FuzzyEn`、`FuzzyIn`、`FuzzyIan`、`FuzzyUan`、`FuzzyUn`、`FuzzyAnAi`、`FuzzyHuangWang`、`FuzzyUnIong`、`FuzzyEngOng` | `Fuzzy` 是总开关，下面各组分别生效 |
| 输入 | `TypoCorrection`、`RareExtChars`、`InputScheme`、`ShuangpinScheme`、`ShuangpinShowKeys`、`WubiAutoCommit`、`WubiHint`、`ShiftToggle` | 按错键纠正、扩展 B 区生僻字、全拼 / 双拼 / 五笔 86、双拼方案、单按哪个 Shift 切中英文 |
| 输出 | `Traditional`、`PunctuationStyle`、`DateTime`、`Calculator`、`EmojiSuggest`、`AutoSpace`、`AutoSpaceLetters`、`AutoSpaceDigits` | 繁体、全角 / 半角标点、日期时间、算式、emoji 推荐、中英文之间自动加空格 |
| 词库 / 工具栏 | `Lexicon`、`Toolbar`、`ClipboardHistory` | 万象词库的路径、`v + 空格` 工具栏、剪贴板历史（默认关，只在内存里） |
| 学习 / 统计 | `AutoLearn`、`InputStatistics` | 选够 3 次的词自动进用户词库（默认开）；每日汉字数和上屏次数（默认关，只在本机保存） |
| 语音 | `Voice`、`VoiceKey`、`VoiceCopy` | 语音开关、语音键（默认右 Option `Alt_R`）、结果同时复制到剪贴板 |
| 快捷键 | `EmojiKey`、`ToggleKey`、`TranslateModeKey` | 表情面板、切换中英文、进出「译」；留空不用。键名如 `Control+period`、`Control+Shift+space` |
| 更新 | `CheckUpdate` | 启动后最多一天检查一次，有新版本在设置「关于」页提示 |
| 翻译 | `Translate`、`TranslateTarget`、`TranslateBaseUrl`、`TranslateModel`、`TranslateFormal`、`TranslateLocal`、`TranslateLocalModel`、`TranslateLlamaServer`、`TranslateIdleMinutes` | 互译开关、目标语言、服务地址和模型、正式语气、本地模型和它的路径、闲置几分钟释放 |

读文件的规矩：

- 开关只认 `True` / `False`，选项区分大小写（`Horizontal`，不是 `horizontal`）；写错了、认不出的用默认值。
- 数字超出范围夹到边上（`PageSize=12` 读成 9），认不出的数字用默认值。
- 键和值两边的空格不算（`PageSize = 5` 读成 5）。
- `[分组]` 下面的行不是设置项；设置窗口写回文件时原样留着。
- 两边带双引号的值去掉引号，`\\`、`\"`、`\n` 还原成反斜杠、引号、换行。

**改设置项（加键、改名、改默认值、范围、可选值）要先改规格 [`spec/config.json`](../spec/config.json)**（可选词库包的规矩在
[`spec/lexicon-pack.json`](../spec/lexicon-pack.json)），`macos/test.sh` 拿它对照 `macos/Sources/Shared/Config.swift`，
对不上 CI 就挂。只有 macOS 有的项（比如 `CandidateFontSize`）在规格里也标了。

macOS 的输入法进程是系统启动的，**不读你 shell 里的环境变量**；改设置请改文件或设置窗口。
测试和开发用的 `MYTYPE_DATA_DIR`、`MYTYPE_SPEC_DIR`、`MYTYPE_SWIFT_DOCKER`、`MYTYPE_UPDATE_*` 只在 `macos/test.sh`、
`macos/ShellTests/run.sh` 里用（见 `README.md` 的测试命令），平时不用管。

## 关于页与更新

0.6.0 起，设置侧栏最后有一页「关于」：

- 当前版本、发布页上的最新版本、检查更新、打开发布页；
- 有新版本时可以「下载并安装」：下载 `MyType-<版本>-macos.pkg`，按同一页的 `SHA256SUMS` 校验，再交给系统的
  `installer -target CurrentUserHomeDirectory`（和 `install.sh` 一样只装给当前用户，不要管理员密码）。
  安装时 MyType 会退出，装完自动重新打开并切回来；
- 「自动检查更新」开关对应 `CheckUpdate`；
- 检查更新走 `https://github.com/yxxbc/MyType/releases/latest` 的 302，只看跳到哪个 tag，**不用 GitHub API**，
  也不下载发布页；下载地址是同一次发布的资产。

装在 `/Library/Input Methods`（管理员安装）的版本不能自动更新，页面上只给发布页链接。

## 数据文件

词库和英文词表：设置里的 `Lexicon`（文件在才用）→ 安装包里的 `MyType.app/Contents/Resources/`。
都找不到时用只有十几个词的演示词库（能打 `nihao`，但没法日常用）。

安装包里带的：`lexicon.tsv`（雾凇拼音）、`english.txt`、`words.lm`、`s2t.tsv`、`wubi86.tsv` 和各自的许可证。

用户数据在 `~/Library/Application Support/MyType/`：

| 文件 | 内容 |
|---|---|
| `mytype.conf` | 设置（本文） |
| `custom.tsv` | 自定义词 / 常用语 |
| `user.tsv` | 自动学到的词和词频 |
| `history.tsv` | 输入习惯（选词热度、词搭配） |
| `input-statistics.json` | 每日汉字数、上屏次数（最多 90 天，设置 →「输入统计」可清除） |
| `translate.key` | 互译的 API Key（0600） |
| `dicts/wanxiang/` | 可选的万象词库 |
| `wtlocal/` | 语音识别模型 |
| `models/`、`llama/` | 本地翻译模型和 llama-server |
| `lexicon.tsv`、`lexicon.tsv.wcache` | 指向安装包词库的链接和载入快照 |

## 可选词库：万象拼音

设置「输入」页可以换成万象拼音（词更多，比雾凇多占约 300 MB 内存）：

- 发布页上的包名是 `wowtype-data-wanxiang-<版本>.tar.gz`（沿用旧名字，0.5.x 也认），
  按同一页的 `SHA256SUMS` 校验，包里有 `lexicon.tsv`、`LICENSE`、`SOURCE.txt`、`VERSION` 四个文件；
- 装在 `~/Library/Application Support/MyType/dicts/wanxiang/`，换词库后几秒生效，自定义词和学到的习惯都保留；
- 数据来自 [amzxyz/rime_wanxiang](https://github.com/amzxyz/rime_wanxiang)（CC BY 4.0），只用了词条；
- 也可以从文件安装（工具栏的文件夹按钮），或者命令行
  `MyType --install-lexicon wanxiang`、`MyType --use-lexicon rime-ice|wanxiang`。
